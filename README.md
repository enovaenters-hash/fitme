# FitMe

Enter your measurements once and see clothes that are in stock in your size.

- **Live app:** https://enovaenters-hash.github.io/fitme/
- `index.html` is the public page (served by GitHub Pages).
- `apps-script/` is a copy of the Google Apps Script backend that reads store inventory and matches sizes. The page calls it at its `/exec?api=search` endpoint.
